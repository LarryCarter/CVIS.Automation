# Lifecycle Reporting

This folder contains lifecycle diagnostics.

## Important

Lifecycle reporting is not the authoritative test count.

Lifecycle logs are useful for debugging setup/teardown behavior, but the real test totals come from:

```text
TestResults\TRX
TestResults\NUnitXml
```

The authoritative HTML report is generated by:

```text
CVIS.Playwright.Reporting.Tool
```

and written to:

```text
TestResults\CPN\cpn-report.html
```

## Do not confuse these

| File | Meaning |
|---|---|
| `cpn-report.html` | authoritative all-tests report |
| `cpn-lifecycle-report.html` | diagnostic lifecycle report only |
